# wut

Restate your last message. Drop the jargon and say it again the way one person
would say it to another: more simply and more concisely.

- Keep the meaning exactly; only the words change.
- No acronyms, internal names, or buzzwords ("leverage", "utilize", "robust").
- Short sentences, concrete words.
- If the last message was long, compress it to a few lines.
- Don't add information, caveats, or new offers. Just restate.

Runs in the current conversation, so "your last message" is the message the
user is reacting to.
